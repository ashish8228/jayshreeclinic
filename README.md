Jayshree Skin Clinic

Live Site: https://ashish8228.github.io/jayshreeclinic/

Overview

Jayshree Skin Clinic is a modern portfolio website showcasing Dr. Seepika Jaiswal and Dr. Hari Mohan Rai’s expertise in dermatology, nutrition, and aesthetic care. Built with Next.js and deployed on GitHub Pages, it features services, testimonials, team info, and contact details—all optimized for performance and SEO.

Features

Responsive design for all devices

Fast static export using Next.js output: "export"

Image assets served from public/images with absolute paths

SEO-friendly meta tags and structured data

Modern React components with TypeScript support

Tailwind CSS styling (if used)

Smooth animations using Framer Motion

Getting Started

Prerequisites:

Node.js and npm installed

Installation:

Clone the repository by running:
git clone https://github.com/ashish8228/jayshreeclinic.git

Change directory to the project:
cd jayshreeclinic

Install all dependencies:
npm install

Local Development:

Start your development server by running:
npm run dev

Open your browser and go to:
http://localhost:3000

Export and Deployment:

Build the project:
npm run build

Export the static files:
npm run export

Deploy the contents of the out/ folder to your GitHub Pages branch (gh-pages).

The site is live at: https://ashish8228.github.io/jayshreeclinic/

Important Notes

Place all images inside the public/images directory and reference them in code using absolute paths like /images/yourfile.png

Image optimization is disabled (unoptimized: true) because the project uses static export.

To update the live site, make your changes and redeploy the out/ directory to GitHub Pages.

Built With

Next.js, React, TypeScript, Tailwind CSS (optional), Framer Motion
