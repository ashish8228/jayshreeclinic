## 🩺 Overview

**Jayshree Skin Clinic** is a modern, elegant portfolio website showcasing  
**Dr. Seepika Jaiswal** and **Dr. Hari Mohan Rai’s** expertise in **Dermatology**, **Nutrition**, and **Aesthetic Care**.  
Built with **Next.js**, the site is fully optimized for **SEO**, **performance**, and **mobile responsiveness** — delivering a smooth, professional experience to visitors.

---

## ✨ Features

- 📱 **Responsive Design** – Works seamlessly on all devices.  
- ⚡ **Fast Static Export** – Using `Next.js` with `output: "export"`.  
- 🖼️ **Optimized Image Handling** – Served from `/public/images` with absolute paths.  
- 🔍 **SEO-Friendly** – Includes meta tags and structured data for better visibility.  
- ⚛️ **Modern React Components** – Built with **TypeScript** support.  
- 🎨 **Tailwind CSS** – For clean, modern styling.  
- 🌀 **Smooth Animations** – Integrated with **Framer Motion**.
